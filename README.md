# QuantumOS 

A futuristic, sci-fi-themed web operating system featuring a custom terminal boot sequence, neon aesthetics, and a fully draggable interface. Built for the Hack Club WebOS mission.

# Live Demo

[Experience QuantumOS Live](https://saikaushilkatta.github.io/QuantumOS) 

# Features

* Custom Window Management: Fully draggable application windows with independent close functionality.
* Integrated Calculator: A functional, neon-styled application for basic arithmetic, seamlessly tied into the window manager.
* Functional Taskbar: A bottom navigation bar utilizing CSS Flexbox to relaunch closed applications.
* Live Telemetry: Real-time digital clock and dynamic system uptime tracker powered by JavaScript.
* Sci-Fi UI/UX: Neon cyan styling, dark mode aesthetics, and a high-definition deep-space background.

# Built With

* HTML5: Core layout and application containers.
* CSS3: Custom UI styling, glowing hover states, and absolute positioning.
* Vanilla JavaScript: DOM manipulation, drag-and-drop coordinate math, and `setInterval` timing functions.

# How to Run Locally

1. Clone this repository: `git clone https://github.com/saikaushilkatta/QuantumOS.git`
2. Open the project directory on your local machine.
3. Double-click `index.html` to run the OS directly in your browser. No build tools or servers required!
